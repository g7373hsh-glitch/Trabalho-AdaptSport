# Guia de versionamento e publicação

Este projeto já possui repositório GitHub e publicação ativa no GitHub Pages.

- **Repositório:** https://github.com/g7373hsh-glitch/Trabalho-AdaptSport
- **Site publicado:** https://g7373hsh-glitch.github.io/Trabalho-AdaptSport/

Os passos abaixo servem para manutenção, conferência e futuras atualizações; não é necessário criar outro repositório ou outra URL.

## Fluxo recomendado para a equipe

1. Para uma melhoria, criar uma branch, implementar a mudança, testar e abrir pull request para `main`, se esse for o fluxo escolhido pela equipe.
2. Após a revisão, fazer merge em `main`; o GitHub Pages publica a versão dessa branch.
3. Conferir o deploy em [https://github.com/g7373hsh-glitch/Trabalho-AdaptSport/settings/pages](https://github.com/g7373hsh-glitch/Trabalho-AdaptSport/settings/pages) e testar a URL pública.
4. Navegar pelas dez páginas e conferir recursos, links, vídeo local e formulário. A função do formulário permanece local e não envia mensagens.
5. Atualizar `repositorio.txt`, README, slides e documentação somente com URLs reais.

A página oficial do GitHub Pages descreve a publicação de arquivos HTML, CSS e JavaScript diretamente do repositório e informa os formatos de site de usuário/organização e de projeto. Verifique limites e condições atualizados na fonte oficial antes de futuras alterações de hospedagem.
