Recomendação e status

Recomendamos GitHub Pages com o subdomínio padrão, sem custo de hospedagem, porque o AdaptSport é estático e requer histórico Git. O domínio próprio .com.br adicionaria R$ 40/ano, se o nome estiver disponível. Como nenhum repositório foi conectado, o deploy não foi feito e a recomendação ainda precisa ser executada pela equipe.
